==================================================
DBT LOCAL PROJECT - QUICK RUN GUIDE
==================================================

1. 日常快速运行 (Daily Run):
   cd dbtyz
   ..\.venv\Scripts\Activate.ps1
   dbt build

==================================================
首次部署 / 更换电脑 / 移动文件夹后重置 (Fresh Setup / Re-setup):
==================================================
如果项目移动到了新路径或在全新电脑克隆，请重新生成虚拟环境：

1. 打开终端（项目根目录 DBT_LOCAL）：
   cd c:\Users\Kerry\OneDrive\code\DBT_LOCAL

2. 重建虚拟环境：
   python -m venv .venv

3. 激活虚拟环境 (PowerShell)：
   .venv\Scripts\Activate.ps1

   *若提示脚本未签名受限，先运行：
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned

4. 安装依赖：
   pip install -r requirements.txt

5. 运行 dbt：
   cd dbtyz
   dbt debug    # 检查连接
   dbt deps     # 安装依赖包
   dbt build    # 构建并测试所有模型
